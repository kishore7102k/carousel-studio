This is the default brand pack. Replace it on the Brand page with your own colors, fonts and voice.

## Voice

- Direct and practical. Write as "I" talking to "you".
- One idea per carousel. The cover hook states the payoff.
- About 25 words per slide. Sentence case. No em dashes, no emoji as bullets.
- Code must be real and tested. Code lines at most 32 characters.

## Visual rules

- Cover and CTA slides use the primary color as the ground.
- Content and code slides sit on paper. Code always sits in the dark editor card.
- Mark exactly one phrase per slide with the highlighter (`*phrase*` in slide text).
- Before/after code is shown as a diff: lines start with "- " or "+ ".
